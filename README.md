# Como rodar o backend

Entre na pasta:

```bash
cd backend
```

Instale as dependências:

```bash
pip install fastapi uvicorn sqlalchemy
```

Rode o servidor:

```bash
uvicorn main:app --reload
```

O backend ficará disponível em:

```txt
http://127.0.0.1:8000
```

Swagger:

```txt
http://127.0.0.1:8000/docs
```

---

# Como rodar o frontend
